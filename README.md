# Port-Scanning-
Port scanning is the process of checking a computer or device on a network to see which ports are open, closed, or filtered. It’s like knocking on each door to see which services respond.
points:
Ports = doors where programs (web server, SSH, FTP, etc.) send/receive data.
Open = a service is listening and can accept connections.
Closed = reachable but no service running.
Filtered = blocked or hidden by a firewall (scanner can’t tell if open).
